# Tante Rie HQ

Gedeelde plek voor het SEO-team (tante-rie-seo), het PIM-team (tante-rie-pim) en het Design-team (tante-rie-design): status, mailbox (Markdown-berichten per team en JSON voor productregels, `scripts/mailbox.py`) en ruwe onderzoeksdata. Werkafspraken: `team/werkafspraken-seo.md`, `team/werkafspraken-pim.md` en `team/werkafspraken-design.md`.

Directie: `.claude/agents/directie.md` leest status en mailboxen van de drie teams (`scripts/directie_overzicht.py`, ook bij sessiestart), bewaakt `team/doelen.md` en schrijft een agenda voor Mark in `team/directie/`.
